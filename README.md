# Calorie Tracker + React TS

This project is a simple calorie tracker to learn how implement useReducer and practice all basics of react like states, effects and memos.

## How use it?

Clone this repo with
`git clone uri`

Open a terminal and install packages using npm, pnpm, yarn, etc
`npm i`, `pnpm install`, `yarn install`

Run this project
`npm run dev`
